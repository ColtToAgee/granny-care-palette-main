# Granny's Warm Welcome

Website Color Palette

A warm, caring and trustworthy visual direction for MTÜ My Granny

Use deep pink as the main brand color, while blue and green remain supporting accents. This keeps the website connected to the logo without making it feel overly colorful or childish.

 Recommended Color Usage

The goal is a balanced interface that feels welcoming and professional.

■ Primary buttons

White text on deep pink. Use for Create Account, Find a Granny, Become a Granny and Send Request.	■ Headings and links

Use the logo blue for important headings, links and selected icons. Avoid using it as a large background.

■ Safety and success

Use green for verification, support, positive status messages and trust-related elements.	■ Backgrounds

Use warm off-white for the page background, white for cards and soft pink or green for highlighted sections.

Recommended color balance

60%	30%	10%

White and very light backgrounds	Primary pink and brand elements	Blue and green accents
